# Draft bilingual terminology

These are authoring conventions checked against the retained EDB learning-content wording. Independent language review is pending. Do not present local wording as an additional official objective.

| English | 繁體中文 | Use and boundary |
| --- | --- | --- |
| directed numbers | 有向數 | Includes negative numbers, zero and positive numbers |
| opposite numbers | 相反數 | Distinguish position/order from distance to zero |
| number line | 數線 | Equal spacing; labelled zero/reference |
| directed change | 有向變化 | Final minus initial, with a stated unit |
| algebraic expression | 代數式 | Different from an equation |
| sum / product / square | 和／積／平方 | Preserve grouping in both languages |
| sequence / general term | 數列／通項 | A prefix guess differs from a supplied general rule |
| triangular numbers | 三角形數 | Required alongside odd/even/square sequences |
| input–processing–output | 輸入—處理—輸出 | Preliminary function idea, with no formal senior definition required |
| linear equation in one unknown | 一元一次方程 | 一元線性方程 is also named in the Chinese source |
| solution / unknown | 解／未知數 | Check a solution against the original equation |
| adjacent angles on a straight line | 直線上的鄰角 | Sum 180°, with the actual straight-line premise |
| vertically opposite angles | 對頂角 | Equal at the intersection; not a test for two target lines being parallel |
| angles at a point | 同頂角 | Sum 360° for the full round angle |
| complementary / supplementary angles | 餘角／補角 | Sums 90° / 180° |
| transversal | 截線 | Intersects the two lines at distinct points; parallelism is not part of the definition |
| corresponding angles | 同位角 | Pair position can be named before knowing parallelism |
| alternate interior angles | 內錯角 | Include actual ray/sector identity in the diagram model |
| interior angles on the same side | 同旁內角 | Use full English phrase where the shorter “interior angles” could be confused with triangle interior angles |
| interior / exterior angle of a triangle | 三角形的內角／外角 | Identify the side extension; exterior equals the two remote interior angles |
| model solution / self-review | 參考解答／自我檢視 | Neither is independent teacher verification |
| first independent answer evidence | 首次獨立作答紀錄 | Local bounded evidence, not a mastery or grade claim |

Subtraction-order examples need special care: “five less than three times x” is 3x−5 (x 的三倍減去五). “Subtract three times x from five” is 5−3x (五減去 x 的三倍). Avoid ambiguous colloquial wording.

## Rational and irrational numbers — planned authoring terms

Checked against the bilingual Unit 4 sources on 22 November 2026 (Hong Kong); independent language review remains pending.

| English | 繁體中文 | Use and boundary |
| --- | --- | --- |
| nth root | n 次方根 | Distinguish the index from a coefficient; negative radicands are allowed for odd real roots. |
| square root / cube root | 平方根／立方根 | The square-root sign denotes the principal nonnegative value. |
| positive square root | 正平方根 | Use for a positive radicand; the principal square root of zero is zero. |
| rational / irrational number | 有理數／無理數 | Classify exact numbers, not the length of a calculator display. |
| recurring decimal | 循環小數 | Explicitly state or mark the repeating block. |
| simple quadratic surd | 簡單二次根式 | Respect the bounded Unit 4 arithmetic scope. |
| simplest surd form | 最簡根式 | Separate an equivalent exact value from the requested simplified form. |
| like surds | 同類根式 | Compare the simplified radical parts. |
| constructible number | 可構造數 | State the straightedge/compass and unit-length assumptions. |
| compasses and straightedge construction | 尺規作圖 | Optional investigation follows the required construction/geometry recap. |

Prefer “在數線上標示大約位置” for an approximate number-line representation. Avoid treating “近似值” as the exact irrational value, or “有理數” as a synonym for a positive fraction.
